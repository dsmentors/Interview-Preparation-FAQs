Basics

Excel and its built-in options.

What is Excel used for?

Excel is a spreadsheet application developed by Microsoft that is primarily used for data organization, analysis, and visualization. It helps users perform tasks like data entry, calculations, financial modeling, creating charts, and generating reports. It is commonly used for accounting, data analysis, inventory management, budgeting, and more.

Explain the difference between a workbook and a worksheet.

A workbook is an Excel file that can contain one or more worksheets. Each workbook serves as a container for multiple worksheets, which are individual sheets where data is entered and manipulated. Think of a workbook as a book, and each worksheet is a page in that book.

What is a cell in Excel?

A cell is the basic unit of a worksheet where data is entered. Each cell is an intersection of a row and a column, and it can hold different types of data such as text, numbers, dates, or formulas.

What is a cell address in Excel?

A cell address (or cell reference) identifies the location of a cell in a worksheet. It is defined by the column letter and row number, for example, B4 refers to the cell in Column B and Row 4.

How do you navigate between worksheets in a workbook?

To navigate between worksheets in a workbook, you can:

  • Click on the sheet tabs at the bottom of the Excel window.
  • Use keyboard shortcuts like Ctrl + Page Up (to move to the previous sheet) or Ctrl + Page Down (to move to the next sheet).
What is the ribbon in Excel?

The ribbon is the toolbar at the top of the Excel window that contains tabs like Home, Insert, Page Layout, Formulas, and more. Each tab includes groups of related commands for performing various tasks such as formatting, inserting objects, performing calculations, and data analysis.

How do you reference a cell in a formula?

To reference a cell in a formula, you use its cell address. For example, to reference cell A1, you would type =A1. You can use cell references to create formulas that perform calculations on data from different cells.

Explain the difference between relative and absolute cell references.
  • Relative references change when a formula is copied to another cell. For example, if you have a formula =A1+B1 in cell C1 and copy it to C2, the formula will change to =A2+B2.
  • Absolute references remain constant, no matter where the formula is copied. They are indicated by a dollar sign ($) before the column letter and row number, like $A$1. If you copy a formula with =$A$1+B1 from C1 to C2, it will remain =$A$1+B2.
What is the order of operations in Excel formulas?

Excel follows the PEMDAS order of operations:

  1. Parentheses
  2. Exponents
  3. Multiplication and Division (left to right)
  4. Addition and Subtraction (left to right)

What are wildcards in Excel?

Wildcards are special characters used in Excel formulas to represent one or more characters. They are helpful when you want to match patterns rather than exact values.

What are the wildcards available in Excel?

The wildcards available in Excel are:

  • Asterisk (*): Represents any number of characters. Example: "A*" matches any text starting with "A".
  • Question mark (?): Represents a single character. Example: "B?g" matches "Bag" or "Big".
  • Tilde (~): Used to escape a wildcard character. Example: "A~?" searches for "A?" instead of interpreting it as a wildcard.

How do we check whether a file exists or not in a specified location?

Excel has no built-in worksheet function that checks whether a file exists. A formula such as =IFERROR(HYPERLINK("C:\path\file.xlsx"), "File does not exist") does not work, because HYPERLINK only creates a link and does not return an error for a missing file.

Use VBA with the Dir function instead:

Sub CheckFile()
    If Dir("C:\path\file.xlsx") <> "" Then
        MsgBox "File exists"
    Else
        MsgBox "File does not exist"
    End If
End Sub
What are the five basic Excel functions?
  1. SUM: Adds numbers in a range.
  2. AVERAGE: Calculates the mean of numbers in a range.
  3. COUNT: Counts the number of cells containing numbers in a range.
  4. MAX: Returns the largest number in a range.
  5. MIN: Returns the smallest number in a range.
What are the five basic Excel formulas?
  1. =SUM(A1:A10): Adds values from A1 to A10.
  2. =AVERAGE(B1:B10): Calculates the average of values from B1 to B10.
  3. =IF(C1>100, "Yes", "No"): Returns "Yes" if C1 is greater than 100, otherwise "No".
  4. =VLOOKUP(D1, E1:F10, 2, FALSE): Searches for a value in the first column of a range and returns a value in the same row from another column.
  5. =COUNTIF(G1:G10, ">50"): Counts the number of cells in G1 to G10 with values greater than 50.

Intermediate

Formulas and functions.

How do you use the IF function in Excel?

The IF function in Excel allows you to make logical comparisons between a value and what you expect. It returns one value if a condition is true and another value if it is false.

  • Syntax: =IF(condition, value_if_true, value_if_false)
  • Example: =IF(A1 > 50, "Pass", "Fail") will return "Pass" if the value in A1 is greater than 50, otherwise it will return "Fail".
What is the difference between a formula and a function in Excel?
  • A formula is a user-defined calculation that combines one or more cells or values with operators (like +, -, *, etc.). For example, =A1 + B1.
  • A function is a predefined formula provided by Excel that performs a specific calculation, such as SUM, AVERAGE, or VLOOKUP. Functions are used within formulas.
What is the difference between COUNT, COUNTA, COUNTIF, COUNTIFS, and COUNTBLANK?
  • COUNT: Counts the number of cells that contain numbers in a range. Example: =COUNT(A1:A10).
  • COUNTA: Counts the number of non-empty cells (both numbers and text) in a range. Example: =COUNTA(A1:A10).
  • COUNTIF: Counts the number of cells that meet a single condition. Example: =COUNTIF(A1:A10, ">5").
  • COUNTIFS: Counts the number of cells that meet multiple criteria. Example: =COUNTIFS(A1:A10, ">5", B1:B10, "<10").
  • COUNTBLANK: Counts the number of empty cells in a range. Example: =COUNTBLANK(A1:A10).
How do we use the SUMIF and SUMIFS functions in Excel?
  • SUMIF: Adds up the values in a range that meet a single criterion.
    • Syntax: =SUMIF(range, criteria, [sum_range])
    • Example: =SUMIF(A1:A10, ">5", B1:B10) adds the values in B1:B10 where the corresponding cells in A1:A10 are greater than 5.
  • SUMIFS: Adds up the values in a range that meet multiple criteria.
    • Syntax: =SUMIFS(sum_range, criteria_range1, criteria1, [criteria_range2, criteria2], ...)
    • Example: =SUMIFS(B1:B10, A1:A10, ">5", C1:C10, "<10") adds values in B1:B10 where A1:A10 is greater than 5 and C1:C10 is less than 10.
Explain the difference between CONCATENATE and CONCAT functions.
  • CONCATENATE: An older Excel function used to join two or more text strings into one. Example: =CONCATENATE(A1, " ", B1).
  • CONCAT: A newer function that serves the same purpose but allows joining ranges or multiple text strings with enhanced flexibility. Example: =CONCAT(A1:B1) joins text from a range more dynamically.
Explain the importance of the MAX and MIN functions in Excel.
  • MAX: Returns the largest number from a set of values. Useful for identifying the highest value in a dataset, like finding the top score or maximum sales.
    • Syntax: =MAX(range)
  • MIN: Returns the smallest number from a set of values. Useful for identifying the lowest value in a dataset, such as the lowest expense or minimum temperature.
    • Syntax: =MIN(range)

What is the purpose of the INDEX-MATCH function?

INDEX-MATCH is used to search and return data from a table or range more flexibly than VLOOKUP:

  • INDEX returns the value of a cell at the intersection of a row and column in a given range.
  • MATCH finds the position of a value in a range.
  • Combined Use: =INDEX(range, MATCH(lookup_value, lookup_range, match_type)).
  • Example: =INDEX(B2:B10, MATCH("John", A2:A10, 0)) returns John's corresponding value from column B.
How do you use the IFERROR function?

The IFERROR function returns a specified value if a formula results in an error; otherwise, it returns the formula's result.

  • Syntax: =IFERROR(value, value_if_error)
  • Example: =IFERROR(A1/B1, "Error: Division by Zero") returns "Error: Division by Zero" if B1 is zero; otherwise, it calculates the division.
Explain the difference between SUBSTITUTE and REPLACE in Excel.
  • SUBSTITUTE: Replaces a specific text string within another text string. It's useful when you want to replace a particular word or character(s) across the entire text or in a specific instance.
    • Syntax: =SUBSTITUTE(text, old_text, new_text, [instance_num])
    • Example: =SUBSTITUTE("apple banana apple", "apple", "orange") changes all occurrences of "apple" to "orange".
  • REPLACE: Replaces text based on its position. You specify where the replacement should start and how many characters to replace.
    • Syntax: =REPLACE(old_text, start_num, num_chars, new_text)
    • Example: =REPLACE("12345", 2, 3, "678") changes "12345" to "16785" by replacing 3 characters starting from the 2nd position.
How can you round a number to a specified number of decimal places in Excel?

To round a number to a specific number of decimal places, use the ROUND function.

  • Syntax: =ROUND(number, num_digits)
    • Example: =ROUND(3.14159, 2) rounds 3.14159 to 3.14.
  • You can also use:
    • ROUNDUP to always round up: =ROUNDUP(3.14159, 2) results in 3.15.
    • ROUNDDOWN to always round down: =ROUNDDOWN(3.14159, 2) results in 3.14.
What is the difference between a line chart and a scatter plot?

The TRIM function removes all extra spaces from a text string, except for single spaces between words.

What is the purpose of the AVERAGEIF and AVERAGEIFS functions?
  • AVERAGEIF: Calculates the average of cells that meet a single criterion.
    • Syntax: =AVERAGEIF(range, criteria, [average_range])
    • Example: =AVERAGEIF(A1:A10, ">50") calculates the average of values greater than 50.
  • AVERAGEIFS: Calculates the average of cells that meet multiple criteria.
    • Syntax: =AVERAGEIFS(average_range, criteria_range1, criteria1, [criteria_range2, criteria2], …)
    • Example: =AVERAGEIFS(B1:B10, A1:A10, ">5", C1:C10, "<10") averages values in B1:B10 where A1:A10 is greater than 5 and C1:C10 is less than 10.

What is a Pivot Table?

A Pivot Table is an Excel feature that allows you to quickly summarize, analyze, explore, and present large sets of data. It helps in aggregating data (like sums, averages, counts) and viewing it from different perspectives.

How do you create a Pivot Table?

To create a Pivot Table:

  1. Select the data range you want to analyze.
  2. Go to the Insert tab and click on PivotTable.
  3. Choose the data range (source) and the location where the Pivot Table will be created.
  4. Click OK. The Pivot Table Field List will appear.
  5. Drag and drop fields into the Rows, Columns, Values, and Filters areas to build your table and analyze your data as needed.
How do you create a column in a Pivot Table?

To create a column in a Pivot Table:

  1. Open the Pivot Table Field List pane.
  2. Drag the field (column name) that you want to appear as a column header into the Columns area of the Pivot Table Field List.
  3. The data will be automatically grouped by that field into columns.
Can you create a Pivot Table using multiple sources of data?

Yes, you can create a Pivot Table using multiple sources of data:

  • Use the Data Model in Excel by importing multiple tables and creating relationships between them using common keys.
  • Alternatively, use Power Query to consolidate data from different sources into a single table.
Can many tables be used to build Pivot Tables?

Yes, many tables can be used to build Pivot Tables:

  • You can add multiple tables to the Data Model and establish relationships between them using key fields.
  • This approach allows you to create a Pivot Table that pulls data from several related tables.
How can I disable Pivot Tables' automatic sorting?

To disable automatic sorting in a Pivot Table:

  1. Click on any cell within the Pivot Table.
  2. Go to the PivotTable Analyze tab (or Options tab).
  3. Click Sort > More Sort Options.
  4. Choose Manual Sort to prevent Excel from automatically sorting the data.
Differentiate between Pivot Charts and Standard Charts.
  • Pivot Charts: Automatically update with changes in the underlying Pivot Table. They are linked to the data summarization in the Pivot Table and can dynamically filter data using Pivot Table filters and slicers.
  • Standard Charts: Created directly from a range of data and do not automatically update unless the source data changes. They do not offer the same interactivity or dynamic filtering as Pivot Charts.
How do you use tables from separate worksheets to create a Pivot Table?

To use tables from separate worksheets:

  1. Convert each data range into a table by selecting it and pressing Ctrl + T.
  2. Add each table to the Data Model by going to Power Pivot > Add to Data Model.
  3. In Power Pivot, create relationships between the tables using common fields.
  4. Go to the Insert tab, click PivotTable, and choose Use this workbook’s Data Model to create a Pivot Table.
Explain how a Slicer works in Excel.
  • Slicers: Visual tools used to filter data in Pivot Tables and Pivot Charts.
    • When you insert a Slicer, it displays buttons representing unique values in a column.
    • Clicking a button filters the Pivot Table data to display only items that match that value.
    • You can add multiple slicers for different fields to provide a more refined filtering experience.
What is the What-If Analysis in Excel?

What-If Analysis allows you to explore different scenarios and outcomes by changing input values. It includes:

  • Scenario Manager: Save and switch between multiple sets of input values.
  • Goal Seek: Find the necessary input value to achieve a desired result.
  • Data Tables: Show the results of multiple what-if scenarios in a single table.
What is the purpose of the NETWORKDAYS function?
  • NETWORKDAYS calculates the number of working days between two dates, excluding weekends and any specified holidays.
    • Syntax: =NETWORKDAYS(start_date, end_date, [holidays])
    • Example: =NETWORKDAYS("2024-01-01", "2024-01-31") returns the number of working days in January 2024 (23).
What is the difference between CONCATENATE and TEXTJOIN functions?
  • CONCATENATE: Combines two or more text strings into one but has no delimiter argument, so any separator must be added manually.
    • Syntax: =CONCATENATE(text1, text2, …)
  • TEXTJOIN: Combines multiple text strings into one, with the option to specify a delimiter (e.g., comma, space).
    • Syntax: =TEXTJOIN(delimiter, ignore_empty, text1, [text2], …)
How is VLOOKUP different from the LOOKUP function?
  • VLOOKUP: Searches for a value in the leftmost column of a table and returns a value in the same row from a specified column.
    • Syntax: =VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
  • LOOKUP: Searches for a value either in a single row or column and returns a corresponding value from the same position in another range.
    • Syntax: =LOOKUP(lookup_value, lookup_vector, [result_vector])
Explain the HLOOKUP function.
  • HLOOKUP: Searches for a value in the top row of a table (horizontal lookup) and returns a value in the same column from a specified row.
    • Syntax: =HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])
    • Example: =HLOOKUP("Product", A1:D4, 3, FALSE) finds "Product" in the top row and returns the value from the third row of the same column.
What is the purpose of the SUBTOTAL function?
  • SUBTOTAL: Performs calculations (like SUM, AVERAGE, COUNT) on a range and ignores rows that are filtered out. Function numbers 1 to 11 still include manually hidden rows, while 101 to 111 also ignore manually hidden rows.
    • Syntax: =SUBTOTAL(function_num, ref1, [ref2], …)
    • Example: =SUBTOTAL(9, A1:A10) sums the range A1:A10 while ignoring rows hidden by a filter. Use =SUBTOTAL(109, A1:A10) to also ignore manually hidden rows.

Advanced (VBA)

Macros and VBA.

What are macros in Excel?

Macros in Excel are sequences of instructions or actions that automate repetitive tasks. A macro is created by recording a series of actions, such as formatting cells, performing calculations, or manipulating data, which can then be replayed with a single command. Macros are written in Visual Basic for Applications (VBA), a programming language provided by Microsoft for automating tasks in Excel and other Office applications.

How do you create a macro in Excel?

To create a macro in Excel:

  1. Go to the "View" tab or the "Developer" tab (if enabled).
  2. Click on "Macros" -> "Record Macro."
  3. Enter a name for the macro, choose a shortcut key (if desired), and select where to store the macro.
  4. Click "OK."
  5. Perform the actions you want to automate.
  6. Click "Stop Recording" when finished.
  7. The macro is now saved and can be run by using the assigned shortcut key or through the Macros menu.
What is the purpose of VBA (Visual Basic for Applications) in Excel?

VBA (Visual Basic for Applications) is a programming language used in Excel to write macros that automate tasks and customize Excel's behavior. VBA enables users to:

  • Create custom functions and formulas.
  • Automate repetitive tasks, such as formatting cells or generating reports.
  • Interact with other Office applications (Word, PowerPoint, etc.).
  • Develop user forms, dialogs, and interactive tools.
  • Extend Excel's capabilities beyond its built-in features.
How does Excel evaluate formulas in terms of the order of operations?

Excel evaluates formulas based on the PEMDAS/BODMAS rule (Parentheses, Exponents, Multiplication and Division, Addition and Subtraction):

  1. Parentheses: Expressions enclosed in parentheses are evaluated first.
  2. Exponents: Next, exponential calculations (e.g., ^ operator) are evaluated.
  3. Multiplication and Division: These operations are performed from left to right.
  4. Addition and Subtraction: Finally, these operations are performed from left to right.

Write a VBA function to check if a number is a prime number or not.
Function IsPrime(number As Integer) As Boolean
    Dim i As Integer
    If number <= 1 Then
        IsPrime = False
        Exit Function
    End If
    For i = 2 To Sqr(number)
        If number Mod i = 0 Then
            IsPrime = False
            Exit Function
        End If
    Next i
    IsPrime = True
End Function

What is the difference between a function and a subroutine in VBA?
  • Function: Returns a value and can be used in Excel formulas. It performs a calculation or returns a result.
  • Subroutine (Sub): Does not return a value. It is used to perform actions or tasks, like manipulating data, automating processes, or displaying messages.
Explain the difference between ThisWorkbook and ActiveWorkbook in VBA.
  • ThisWorkbook: Refers to the workbook where the VBA code is written and stored, regardless of which workbook is currently active.
  • ActiveWorkbook: Refers to the workbook that is currently open and active, which may or may not be the workbook where the VBA code resides.
How will you pass arguments to a VBA function?

Arguments are passed to a VBA function by specifying them in the function call:

Dim result As Double
result = CalculateArea(5, 10)  ' Passing 5 and 10 as arguments to the CalculateArea function
How do you debug VBA code?

To debug VBA code:

  • Use Breakpoints: Click in the margin of the code window to set breakpoints at specific lines where execution should pause.
  • Step Through the Code: Use "F8" to execute the code line-by-line to observe the flow and variables.
  • Immediate Window: Use the Immediate window (Ctrl + G) to test code snippets, print variable values, or execute statements.
  • Watch Window: Add variables to the Watch window to monitor their values during execution.
  • Error Handling: Use On Error statements to manage and handle errors.
How do you create a macro to automate a task?

To create a macro to automate a task:

  1. Go to the "Developer" tab (enable it if it's not visible).
  2. Click "Record Macro."
  3. Enter a name, shortcut key, and location for the macro.
  4. Perform the actions you want to automate.
  5. Click "Stop Recording" when done.
  6. The macro can now be run to automate the task.
What is the purpose of the PMT function in Excel?

The PMT function in Excel calculates the periodic payment for a loan or investment based on constant payments and a constant interest rate. It's typically used to determine monthly payments on a loan.

Syntax:

=PMT(rate, nper, pv, [fv], [type])
  • rate: Interest rate per period.
  • nper: Total number of payment periods.
  • pv: Present value or principal amount.
