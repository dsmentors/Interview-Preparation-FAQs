Frequently Asked Questions

Q1What is feature engineering in machine learning?

Feature engineering is the process of transforming raw data into meaningful features that improve the performance of machine learning models. It involves selecting, modifying, or creating new features from the existing data to enhance predictive accuracy.

Q2Why is feature engineering important?

Feature engineering is crucial because the quality and relevance of the features directly affect the model’s performance. Well-engineered features help algorithms better understand patterns in the data, resulting in more accurate predictions and faster model training.

Q3What are the common techniques used in feature engineering?

Some common techniques include:

  • Handling missing data
  • Encoding categorical variables
  • Feature scaling
  • Creating interaction terms
  • Binning
  • Dimensionality reduction
Q4What is feature selection, and how does it help reduce overfitting and computational cost?

Feature selection is the process of identifying the most important features that contribute to the predictive performance of the model, by eliminating irrelevant or redundant features.

It helps in several ways:

  • Reduces dimensionality and improves model performance.
  • Reduces overfitting: by keeping only the most relevant features, the model becomes less complex and does not learn noise in the data.
  • Reduces computational cost: fewer features mean less computation for training and inference, faster training and evaluation, and lower memory usage.
Q5What is the difference between feature selection and feature extraction?
Feature selection Feature extraction

Example Dropping columns with low importance Turning many columns into a few principal components with PCA
Q6What is the curse of dimensionality and how does it affect feature engineering?

The curse of dimensionality refers to the exponential increase in data points required to cover increasing dimensions. As the number of features increases, the data becomes sparse, making it harder for models to find meaningful patterns.

Feature engineering techniques like feature selection and dimensionality reduction help mitigate this issue.

Q7How does feature scaling affect machine learning models? Is it needed for tree-based models?

Feature scaling ensures that numerical features are on a similar scale, preventing features with larger values from disproportionately influencing the model. It is especially important for gradient-based algorithms and distance-based models.

Tree-based models: scaling techniques like normalization and standardization are generally not required, as these models are insensitive to feature scaling. However, scaling can still be useful for other model types in the same pipeline.

Q8What is one-hot encoding, and when should it be used? How does it relate to dummy variables?

One-hot encoding converts categorical variables into binary vectors. Each category is represented as a binary vector with a single "1" in the position corresponding to the category and "0"s elsewhere. It is used when the categorical variables are nominal.

Example: for a Color feature, Red → [1, 0, 0], Green → [0, 1, 0], Blue → [0, 0, 1].

Dummy variables are binary variables created from categorical data to represent the presence or absence of a category. One-hot encoding is the most common way to create them.

Q10What is target (mean) encoding, and when is it useful?

Target encoding, also called mean encoding, replaces categorical values with the mean of the target variable for each category. It captures the relationship between the category and the target variable.

It is useful for high-cardinality categorical variables, as it reduces dimensionality while preserving predictive information.

Q11How do you handle missing data in feature engineering? What is imputation?

Missing data can be handled by:

  • Imputation: filling missing data with estimated values (e.g., mean, median, or a model prediction).
  • Deletion: removing rows or columns with missing data.
  • Algorithms that handle missing data natively.

Imputation is necessary to avoid losing data and to prevent biases that missing values may introduce in the model.

Q12What is polynomial feature generation, and how can it help improve model performance?

Polynomial feature generation creates new features by raising existing numerical features to a power or by multiplying features together. This allows models to capture nonlinear relationships between the features and the target variable, so it is useful when such relationships exist.

Example: from x1 and x2, create x1², x2² and x1·x2.

Q13What is feature interaction, and how can it help in feature engineering?

Feature interaction refers to creating new features by combining two or more existing features. This helps capture relationships that may not be obvious in the individual features alone.

The interaction effect occurs when the impact of one feature on the target variable depends on the value of another feature. Creating interaction features helps the model capture these relationships more effectively.

Q15How can dimensionality reduction techniques improve feature engineering?

Dimensionality reduction techniques, such as PCA and LDA, help reduce the number of features by transforming them into a smaller set of new features that capture the most variance or separate classes.

Q16What is feature importance, and how do you measure it?

Feature importance refers to the contribution of each feature to the predictive power of a model. It can be measured using:

  • Model-specific methods, like Gini importance.
  • Model-agnostic methods, like permutation importance.
Q17What is multicollinearity, and how does it impact feature engineering?

Multicollinearity occurs when two or more features are highly correlated, leading to redundancy. This can cause issues in models like linear regression by inflating variance estimates and reducing interpretability.

It can be addressed by removing correlated features or using regularization techniques.

Q18How do you deal with outliers in feature engineering?

Outliers are data points significantly different from others in the dataset.

  • Detecting them: through statistical methods, visualization, or machine learning techniques like isolation forests or DBSCAN.
  • Handling them: by removing them, transforming the data, or capping and flooring the values.
Q19What are derived features, and how are they created?

Derived features are new features created from the existing ones through mathematical transformations or domain-specific knowledge. They can help capture relationships that may not be apparent in the raw data.

Q20What is binning in feature engineering?

Binning is the process of converting continuous numerical variables into categorical variables by dividing the data into intervals, or bins. It can help reduce the impact of outliers and capture non-linear relationships between features.

Q21What is the role of domain knowledge in feature engineering?

Domain knowledge helps identify relevant features, transform raw data into meaningful representations, and uncover hidden relationships that improve the model’s performance.

Q22How does handling imbalanced data relate to feature engineering?

Handling imbalanced data is part of feature engineering when the target variable is skewed. Techniques such as resampling, SMOTE, or modifying features so that they better represent minority classes can help improve the model's performance on imbalanced datasets.

Q23What is feature hashing, and when is it useful?

Feature hashing maps categorical variables to a fixed-size numerical feature vector using a hash function. It is useful for high-cardinality categorical variables where one-hot encoding would create a very large number of features.

Q24How can log transformation be used in feature engineering?

Log transformation reduces the skewness of the data by transforming features with a wide range of values or highly skewed distributions, making them more normally distributed and suitable for models like linear regression.

Q25What is discretization, and how is it different from binning?

Discretization is the process of converting continuous data into discrete intervals. It is similar to binning, but it can involve more advanced techniques, such as decision trees, to determine the optimal splits rather than using equal intervals.

Q26What is the importance of handling categorical features in feature engineering?

Handling categorical features properly is important because many machine learning algorithms cannot process categorical data directly. Encoding techniques like one-hot encoding, label encoding and target encoding convert categorical features into numerical values suitable for modeling.

Q27What are temporal features, and how can they be engineered?

Temporal features are time-based features, such as day of the week, month or time of day. They can be extracted from date and time variables to capture patterns related to time in the data.

Example: from a timestamp, extract day_of_week, month, hour and is_weekend.

Q28What is frequency encoding in feature engineering?

Frequency encoding assigns a numeric value to each category in a categorical variable based on how often that category occurs. This technique preserves the information about how common each category is in the dataset.

Q29How do you handle multivariate time series in feature engineering?

Handling multivariate time series involves creating:

  • Lagged features
  • Moving averages
  • Seasonal and trend components

Feature engineering in time series helps models understand the temporal dependencies between variables.

Q30What is target leakage, and how can it be avoided during feature engineering?

Target leakage occurs when features contain information from the target variable that would not be available at prediction time.

It can be avoided by making sure that features only use data that will actually be available at the time of prediction, and by building the training features in exactly the same way.

Q31How does dimensionality reduction help in feature engineering for text data?

Dimensionality reduction techniques like Latent Semantic Analysis (LSA) or Principal Component Analysis (PCA) can help reduce the number of features generated from text data while preserving important information, improving computational efficiency.

Q32What is principal component analysis (PCA), and how is it applied in feature engineering?

PCA is a dimensionality reduction technique that transforms features into a set of orthogonal components that explain the maximum variance in the data. It helps reduce the number of features while retaining essential information.

Q33How can embedding techniques be used in feature engineering?

Embedding techniques, such as word embeddings or entity embeddings, convert categorical or textual data into dense vector representations that capture relationships between categories or words. This is useful for handling high-dimensional data in machine learning models.

Q34How does encoding cyclical features improve feature engineering?

Cyclical features are time-related variables such as hours or days of the week. Encoding them involves representing them as sine and cosine components, which ensures that cyclical relationships are captured by the model and reflects the continuous nature of such features (for example, hour 23 is close to hour 0).

sin_x = sin(2π · x / period)
cos_x = cos(2π · x / period)

Q36What are lag features, and when are they useful?

Lag features are the values of previous time steps used as features in time series models. They help capture temporal dependencies, which makes them useful in forecasting tasks, where past observations help predict future values.

Example: to predict today’s sales, use sales_t-1 (yesterday) and sales_t-7 (a week ago) as features.
