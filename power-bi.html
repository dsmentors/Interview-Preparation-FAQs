Q1What are the important components of Power BI?

The important components of Power BI are:

  1. Data Integration: connecting to and combining data from multiple sources.
  2. Data Processing: cleaning, transforming and modeling the data.
  3. Data Presentation: showing the data as visuals in reports and dashboards.
Q2What is a DAX Function?

DAX (Data Analysis Expressions) is a formula language used in Power BI, Power Pivot and SSAS to create custom calculations. DAX functions are similar to Excel functions but are optimized for data models and analytical computations.

Example:

Total Sales = SUM(Sales[SalesAmount])

This DAX formula calculates the total sales by summing the SalesAmount column in the Sales table.

Q4What are the different kinds of Views in Power BI?
  • Report view: the default view in Power BI Desktop, where you create and arrange visualizations.
  • Data view: shows your data in tabular form, so you can inspect it and work with transformations and calculations.
  • Model view: used to manage relationships between tables and set up your data model.

Q7What is grouping? How can you use it?

Power BI Desktop lets you group data points into smaller chunks:

  1. In the visual, hold Ctrl and click to select multiple elements.
  2. Right-click one of the selected elements and choose Group.
  3. The elements appear together in the groups window, where you can name the group.

Example: in a bar chart showing sales by product category, you can group similar categories (for example "Electronics" and "Gadgets") to view them as a single group.

Q8Explain the term responsive slicers.

Responsive slicers in Power BI automatically resize and adjust to fit the available space on your report page. They stay interactive and usable on different screen sizes and devices.

Example: a responsive slicer might reduce the number of visible items or change its layout on smaller screens.

Q9Define the term ‘M language.’

M language is the formula language used in Power Query for data transformation and shaping. It is a functional, case-sensitive language used to create data queries.

Q10What information is required to create a map in Power Map?
  • Geographical data: latitude and longitude coordinates, or address information such as city, state, country or ZIP code.
  • Time data (optional): to visualize changes over time, you can include time-based data such as dates or times.
Q11What are the important features of the Power BI dashboard?
  • Tiles: each visualization in a Power BI dashboard is represented as a tile.
  • Natural language query: lets users ask questions in plain English and get answers as visualizations.
  • Interactive visuals: dashboards are interactive, so users can drill down and filter data.
  • Real-time data: dashboards can display real-time data using streaming datasets.
Q12How can you analyze Power BI reports data in Excel?
  1. Open the Power BI Admin portal, go to Tenant settings and select Analyze.
  2. Check whether the Power BI administrator has enabled the Excel option.
  3. In the upper right corner, click Settings to download and install the Excel updates.
  4. In the left-hand navigation pane, go to the workspace, click the ellipsis (three dots) of the dataset and select Analyze in Excel.
  5. Download the ODC file, save it and double-click it.
  6. Sign in with your Power BI user id and password.
Q13What is Power Pivot, and what are the filters written in Power BI?

Power Pivot is an Excel add-in used for data modeling, creating complex calculations with DAX, and building relationships between tables. It enables large-scale data analysis and the creation of complex data models.

Filters in Power BI restrict the data displayed in reports and visuals. They can be applied at various levels:

  • Report level: affects all pages in a report.
  • Page level: affects all visuals on a single report page.
  • Visual level: affects only a specific visual on a report page.
Q14How can you perform Dynamic filtering in Power BI?

Dynamic filtering in Power BI is done using slicers, filters or DAX measures that respond to user input. For example, you can use a slicer to let users filter data by date range, and the visuals update dynamically to reflect the selection.

Example: a slicer for selecting a year, which dynamically filters the sales data for that year across all visuals in the report.

Q15What is the Power Pivot Data Model?

The Power Pivot Data Model is an in-memory data modeling engine that lets you create a data model in Excel or Power BI. It supports large datasets, complex relationships and advanced calculations using DAX. The model is built by importing data from multiple sources, defining relationships, and creating calculated columns and measures.

Example: a data model that combines sales data from different regions, links the tables through common fields such as RegionID, and calculates total sales per region with DAX measures.

Q16What is a Power Query?

Power Query is a data connection and transformation tool in Power BI (also available in Excel). It lets users import data from various sources, clean and transform it, and load it into the data model for analysis. It is particularly useful for data wrangling, combining datasets and automating repetitive data processing tasks.

Example: importing a CSV file, removing unnecessary columns, and combining it with another dataset from an SQL database.

Q17What are Tiles in Power BI?

Tiles are the individual visual elements that make up a dashboard. Each tile represents a single visualization, such as a chart, map or KPI, and can be pinned from reports or created directly on the dashboard. Tiles can be resized, moved and customized to fit the dashboard layout.

Example: a tile showing total sales on a dashboard that summarizes key performance indicators.

Q18What is an on-premises gateway? Is on-premises access possible in Power BI?

An on-premises gateway is a bridge that enables secure data transfer between on-premises data sources (such as SQL Server or file systems) and the Power BI service in the cloud.

Yes, on-premises access is possible in Power BI through this gateway. It lets users refresh datasets, run queries and keep reports and dashboards current, without moving the data to the cloud.

Q19Name two types of connectivity modes in Power BI?
  1. Import mode: data is imported into Power BI, stored in memory and refreshed periodically. It gives high performance and supports complex data modeling and calculations.
  2. DirectQuery mode: Power BI queries the data directly from the data source at runtime. It is used for large datasets or when real-time data access is required.
Q20What is a calculated column?

A calculated column is a new column created by defining a DAX expression. It is computed row by row for the table and stored in the data model. Calculated columns are useful for deriving new information from existing data.

Example: a "Total Sales" column that multiplies Quantity and Price in a Sales table:

Total Sales = Sales[Quantity] * Sales[Price]
Q21Explain data source filter.

A data source filter is applied when data is imported into Power BI using Power Query. It restricts the amount of data loaded into the model by filtering out unnecessary rows at the source level, which can improve performance and reduce the size of the dataset.

Example: applying a filter to import only the last five years of data from a database table.

Q22Why use a selection pane in Power BI?

The Selection Pane lets you manage the visibility of the visuals on a report page. It is especially useful for complex reports with multiple overlapping visuals. You can show, hide or reorder visuals easily.

Example: temporarily hiding a visual during the design process, or setting up buttons that show or hide visuals based on user interaction.

Q23How to handle Many to Many relationships in Power BI?

To handle a many-to-many relationship, you can use a bridge (intermediary) table that breaks it down into two one-to-many relationships. Alternatively, you can use the newer feature that allows direct many-to-many relationships through composite models.

Example: a bridge table that contains the unique combinations of keys from the two tables, used to establish the relationship.

Q24Explain xVelocity (in-memory analytics).

xVelocity (also known as the VertiPaq engine) is the in-memory analytics engine used by Power BI and SQL Server Analysis Services (SSAS). It uses columnar storage and data compression to load large datasets into memory, which makes data retrieval and analytical operations extremely fast.

Example: loading millions of rows of sales data into memory, which enables quick aggregation and slicing in Power BI.

Q25State the main difference between DISTINCT() and VALUES() in DAX?

Both functions return a unique list of the values in a column. The difference is how they treat the blank row:

  • VALUES() also returns the blank row that Power BI adds when a relationship has unmatched rows (a referential integrity violation).
  • DISTINCT() does not return that added blank row. A blank value that really exists in the column is still returned.

Example: if a fact table has a key that does not exist in the dimension table, VALUES(Dim[Key]) includes a blank for it, while DISTINCT(Dim[Key]) leaves it out.

Q26State the major differences between MAX and MAXA functions.
  • MAX: returns the maximum value in a column, considering only numeric values.
  • MAXA: returns the maximum value in a column, but also evaluates logical values (TRUE = 1, FALSE = 0) and non-numeric data as part of its calculation.

Example: in a column with numbers and logical values, MAXA() treats TRUE as 1, whereas MAX() considers only the numeric values.

Q27What kind of data can you store in Power BI?
  • Fact tables: the central table in the star schema of a data warehouse. It stores the quantitative information used for analysis, and is not normalized in most cases.
  • Dimension tables: tables in the star schema that store the attributes and dimensions describing the objects stored in a fact table.
Q28State the main difference between Filter and Slicer.
  • Filter: applied at the report, page or visual level to limit the data shown. It is not visible to the report user.
  • Slicer: a visual element that lets users interactively filter the data in a report.

Example: a slicer for selecting a product category lets users change what is displayed, while a filter applied to a visual limits the data based on predefined criteria.

Q29How do you use Buttons in Power BI?

Buttons are interactive elements used to perform actions such as navigating to other report pages, drilling through data, or triggering bookmarks. They improve user interactivity and experience in a report.

Example: a button labeled "Go to Details" that takes users to a detailed report page when clicked.
