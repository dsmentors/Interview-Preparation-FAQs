What is the difference between lists and tuples?

Lists are mutable, ordered collections of items, written in square brackets [].

Tuples are immutable, ordered collections, written in parentheses ().

What is the difference between mutable and immutable data types?

Mutable data types can be changed after creation (e.g. lists, dictionaries, sets).

Immutable data types cannot be changed after creation (e.g. strings, tuples, numbers).

What is a decorator?

A decorator is a function that modifies the behavior of another function. It wraps the original function to extend its behavior without permanently modifying it.

def log_call(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log_call
def greet(name):
    return f"Hello, {name}!"

print(greet("Alice"))
# Calling greet
# Hello, Alice!

What is an exception in Python? How do you handle exceptions?

An exception is an error that occurs during program execution. The try, except and finally blocks are used to handle exceptions.

  • try: contains the code that might raise an exception.
  • except: runs only if an exception occurs in the try block.
  • else (optional): runs only if no exception occurs.
  • finally: always runs, whether or not an exception occurred.
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")
else:
    print(result)
finally:
    print("Done")
# Cannot divide by zero
# Done
What is raise in Python?

The raise statement is used to manually trigger an exception. It is useful when you want to signal that an error or exceptional condition has occurred in your program.

By raising an exception, you transfer control to exception handling code, which can manage or respond to the error appropriately.

Syntax:

raise ExceptionType("message")

Example:

def divide(a, b):
    if b == 0:
        raise ZeroDivisionError("Division by zero is not allowed.")
    return a / b

try:
    result = divide(10, 0)
except ZeroDivisionError as e:
    print(e)  # Output: Division by zero is not allowed.
What is a custom exception?

A custom exception is an exception you create yourself by defining a new class that inherits from Python's built-in Exception class (or one of its subclasses). Custom exceptions let you define specific error conditions in your code and raise them when needed.

Example:

# Define a custom exception
class CustomError(Exception):
    pass

# Function that raises the custom exception
def check_value(value):
    if value < 0:
        raise CustomError("Value cannot be negative.")
    return value

try:
    check_value(-1)
except CustomError as e:
    print("Caught a custom exception:", e)
# Output: Caught a custom exception: Value cannot be negative.

What is the purpose of break, continue and pass in Python?

break

  • Terminates the loop: when encountered, the loop is exited immediately and the program continues with the next statement after the loop.

What is the Global Interpreter Lock (GIL) in Python?

The Global Interpreter Lock (GIL) is a mutex (mutual exclusion lock) that protects access to Python objects, preventing multiple threads from executing Python bytecode at the same time in a multi-threaded program. The lock is needed because CPython's memory management is not thread-safe.

The GIL ensures that only one thread executes in the Python interpreter at any one time. This simplifies memory management and garbage collection, but it also limits the concurrency of CPU-bound Python programs.

What is a recursive function in Python? Give an example.

A recursive function is a function that calls itself. It needs a base case to stop the recursion. Here is a recursive function that calculates the factorial of a number:

def factorial(n):
    if n == 0:        # base case
        return 1
    else:
        return n * factorial(n - 1)

print(factorial(5))  # Output: 120

What is the difference between methods and functions?

Functions

A function is a block of reusable code that performs a specific task, defined using the def keyword. Functions can be defined at global scope, inside modules, or inside other functions (nested functions).

  • They are not inherently associated with any object or class.
  • They are called by name followed by parentheses, optionally passing arguments.

Example:

def greet(name):
    return f"Hello, {name}!"

print(greet("Alice"))  # Output: Hello, Alice!

Methods

A method is a function that is associated with an object and defined inside a class. Methods operate on the data contained in the objects of that class. They are called on an object using dot notation, and the object instance is passed implicitly as the first argument, conventionally named self.

Example:

class Greeter:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Hello, {self.name}!"

greeter = Greeter("Alice")
print(greeter.greet())  # Output: Hello, Alice!
What is slicing in Python?

Slicing is a technique used to extract a portion of a sequence such as a list, tuple or string. It uses the colon : operator inside square brackets: sequence[start:stop:step].

  • start: the starting index of the slice (inclusive). Defaults to 0.
  • stop: the ending index of the slice (exclusive), so the slice includes elements up to, but not including, this index. Defaults to the length of the sequence.
  • step: the step size, i.e. how many elements to skip. Defaults to 1.

Example:

my_list = [0, 1, 2, 3, 4, 5]
print(my_list[:3])   # Output: [0, 1, 2]
print(my_list[3:])   # Output: [3, 4, 5]
print(my_list[::2])  # Output: [0, 2, 4]
Explain the *args and **kwargs syntax in Python.

*args passes a variable number of non-keyword arguments to a function. They are collected into a tuple inside the function.

**kwargs passes a variable number of keyword arguments to a function. They are collected into a dictionary inside the function.

Example: *args

def my_function(*args):
    for arg in args:
        print(arg)

my_function(1, 2, 3, "hello")  # Output: 1 2 3 hello (one per line)

Example: **kwargs

def my_function(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

my_function(name="Alice", age=30, city="New York")
# name: Alice
# age: 30
# city: New York
What is the difference between the is and == operators in Python?
  • is checks whether two variables refer to the same object in memory (identity).
  • == checks whether two objects have the same value (equality).
a = [1, 2, 3]

What is the difference between map, filter and reduce in Python?
  • map applies a given function to each item of an iterable and returns an iterator.
  • filter keeps the items of an iterable for which a given function returns true, and returns an iterator.
  • reduce applies a function cumulatively to the items of an iterable and reduces it to a single value. It must be imported from functools.
from functools import reduce

nums = [1, 2, 3, 4]
print(list(map(lambda x: x * 2, nums)))         # [2, 4, 6, 8]
print(list(filter(lambda x: x % 2 == 0, nums)))  # [2, 4]
print(reduce(lambda a, b: a + b, nums))          # 10
Explain method overriding and provide an example.

Method overriding occurs when a subclass provides its own implementation of a method that is already defined in its parent class.

Key points:

  • Overriding allows customization of inherited behavior.
  • The version of the method that runs depends on the type of the object.
  • The overriding method should keep the same name and parameters as the parent method.

Example:

class Animal:
    def make_sound(self):
        print("Generic animal sound")

class Dog(Animal):
    def make_sound(self):
        print("Woof!")

class Cat(Animal):
    def make_sound(self):
        print("Meow!")

# Create objects
animal = Animal()
dog = Dog()
cat = Cat()

# Call make_sound on different objects
animal.make_sound()  # Output: Generic animal sound
dog.make_sound()     # Output: Woof!
cat.make_sound()     # Output: Meow!
  • The Animal class defines a general make_sound method.
  • The Dog and Cat classes override make_sound to provide their own sounds.
  • When we call make_sound on each object, the overridden version for that object's type is executed.

What is an iterator?

An iterator is an object that implements the iterator protocol, which consists of two methods:

  • __iter__(): returns the iterator object itself.
  • __next__(): returns the next item in the sequence, and raises StopIteration when there are no more items.

Iterators are used to traverse iterable objects such as lists, tuples and strings. They are created using the iter() function.

my_list = [1, 2, 3]
my_iter = iter(my_list)
print(next(my_iter))  # Output: 1
print(next(my_iter))  # Output: 2
What is a generator?

A generator is a special type of iterator created using a function with the yield keyword. Calling a generator function returns a generator object without running the function body immediately.

Execution pauses at each yield statement, saving its state and returning the yielded value. The next time next() is called, the function resumes from where it left off.

def my_generator():
    for i in range(5):
        yield i

my_gen = my_generator()
print(next(my_gen))  # Output: 0
print(next(my_gen))  # Output: 1
What are the modes in file handling?

A file mode defines how a file is opened. The common modes are:

  • "r": read mode (default). Opens a file for reading.
  • "w": write mode. Opens a file for writing (creates a new file or truncates an existing one).
  • "a": append mode. Opens a file for appending (writes data at the end of the file).
  • "b": binary mode. Used together with other modes to open a file in binary format (e.g. "rb", "wb").
  • "x": exclusive creation mode. Creates a new file and raises an error if the file already exists.
with open("example.txt", "r") as file:
    content = file.read()  # reads the entire file
    print(content)
Can you explain the zip concept in Python?

The built-in zip function combines two or more iterables (e.g. lists, tuples) into a single iterator of tuples. Each tuple contains the elements from each iterable at the same index, so it "zips" the iterables together element by element.

Key points:

  • zip takes multiple iterables and combines them element-wise into tuples.
  • The result is as long as the shortest input iterable. If the iterables have different lengths, it stops at the end of the shortest one.
  • It returns an iterator of tuples. To get a list of tuples, pass the result to list().
list1 = [1, 2, 3, 4]
list2 = ['a', 'b', 'c']
zipped = zip(list1, list2)
print(list(zipped))  # Output: [(1, 'a'), (2, 'b'), (3, 'c')]
Can you explain the concept of concurrency in Python?

Concurrency is the ability of a program to handle multiple tasks at the same time, or at least give the appearance of doing so. Python supports it in three main ways, each with its own use cases, advantages and limitations:

  • Threading: multiple threads run inside a single process and share memory (threading module). Best for I/O-bound tasks such as network calls or file reads. Because of the GIL, threads do not run Python code in parallel, so it does not speed up CPU-bound work.
  • Multiprocessing: multiple processes run independently, each with its own memory and its own interpreter (multiprocessing module). Gives true parallelism across CPU cores, so it suits CPU-bound tasks.
  • Asynchronous programming: a single thread runs an event loop that switches between tasks while they wait, using async/await (asyncio module). Best for handling many I/O-bound tasks efficiently, such as thousands of network requests.
What is the difference between multiprocessing and multithreading?

Multiprocessing uses multiple processes to perform tasks concurrently. Each process runs independently and has its own memory space. Tasks can run in parallel on multiple CPU cores, which suits CPU-bound tasks.

Key points:

  • Independent processes
  • True parallelism
  • No GIL limitation
  • Inter-process communication (IPC) needed to share data

Multithreading uses multiple threads within a single process. Threads share the memory space and resources of the process, which makes communication between them easier and more efficient.

Key points:

  • Shared memory space
  • Concurrency but limited parallelism
  • Simpler communication
  • Lightweight

Can you describe object-oriented programming and its concepts?

Object-oriented programming (OOP) is a programming paradigm built around objects, which are instances of classes. The key concepts are:

  • Class: a blueprint or template for creating objects. It defines the properties (attributes) and behaviors (methods) that objects of the class have.
  • Object: an instance of a class. Objects are created from the structure defined by the class and can interact with each other to perform tasks.
  • Encapsulation: bundling data (attributes) and the methods that operate on it into a single unit (the class). It hides the internal state and requires interaction to go through the object's methods.
  • Inheritance: the mechanism by which one class inherits properties and behaviors from another. The class being inherited from is the base class or superclass, and the class inheriting is the derived class or subclass. Inheritance promotes code reuse and allows hierarchical relationships between classes.
  • Polymorphism: the ability of different objects to respond in their own way to the same method call. Methods can be written to handle objects of a certain class and also work with its subclasses, which can override or extend the superclass behavior.
  • Abstraction: hiding complex implementation details and showing only the essential features of an object. It reduces complexity and improves understandability.
What is the difference between multiple inheritance and multilevel inheritance?

Both are ways to build relationships between classes, but they differ in structure and in how classes inherit from each other.

Multiple inheritance

  • Definition: a class inherits attributes and methods from more than one parent class.
  • Example: given classes A and B, a third class C can inherit from both A and B at the same time.
  • Usage: useful when a class needs behaviors and attributes from several sources. It can lead to complexity and ambiguity known as the diamond problem, when two parent classes share a common ancestor. Python resolves this using the method resolution order (MRO).
class A:
    pass

class B:
    pass

class C(A, B):  # multiple inheritance
    pass

Multilevel inheritance

  • Definition: a chain of inheritance where a derived class serves as the base class for another class, forming a hierarchy.
  • Example: class A is inherited by class B, and class B is inherited by class C.
  • Usage: sets up a parent-child relationship where each subclass inherits attributes and methods from its immediate superclass.
class A:
    pass

class B(A):
    pass

class C(B):  # multilevel inheritance
    pass

Key differences

  • Structure: multiple inheritance inherits from several classes at the same level, whereas multilevel inheritance is a chain in which each subclass inherits from its immediate superclass.
  • Complexity: multiple inheritance can lead to the diamond problem. Multilevel inheritance is a linear hierarchy, so it is simpler to structure and manage.
  • Usage: multiple inheritance is used when a class needs several sources at once, while multilevel inheritance builds a hierarchy where each subclass adds more specific behavior.
