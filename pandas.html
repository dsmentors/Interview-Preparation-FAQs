What is Pandas?

Pandas is a Python library built on top of NumPy, designed for efficient data manipulation and analysis. It provides high-performance, easy-to-use data structures and data analysis tools. Pandas is particularly useful for handling large datasets, and it is a cornerstone library in data science and machine learning workflows.

What are the different types of data structures in Pandas?

Pandas primarily offers two fundamental data structures:

  • Series: a one-dimensional labeled array capable of holding any data type (integers, strings, floats, Python objects, etc.). It is similar to a NumPy array but with an index. It can be created from a list, array or dictionary.
  • DataFrame: a two-dimensional labeled data structure with columns of potentially different data types. It can be created from a list of dictionaries, a NumPy array, a Series or another DataFrame.

What is a Series in Pandas?

A Pandas Series is a one-dimensional labeled array capable of holding any data type. Think of it as a single column in a spreadsheet or database table. It is built on top of NumPy arrays and offers more flexibility and functionality.

Key characteristics of a Series:

  • Data: can hold any data type (integers, floats, strings, objects, etc.).
  • Index: labels for each data point. By default, it is a range of integers starting from 0.
  • Name: an optional name for the Series.

Example:

import pandas as pd
import numpy as np

data = ['apple', 'banana', 'cherry']
series = pd.Series(data)  # Create a Series from a list

data = np.array(['a', 'b', 'c'])
series = pd.Series(data)  # Create a Series from a NumPy array

Key operations on a Series:

  • Indexing and slicing: accessing elements using labels or positions.
  • Mathematical operations: applying arithmetic, logical and comparison operations.
  • Sorting: sorting values based on the index or the data.
  • Filtering: selecting elements based on conditions.
  • Aggregation: performing calculations like sum, mean, median, etc.
What are the different ways to create a Series?

There are many ways to create a Pandas Series. A few of them are shown below with examples.

  • Empty Series: call the pandas.Series() constructor without any data.
  • Series from an array: import NumPy and pass an array created with np.array() to the constructor.
  • Series from a list: pass a Python list to the Series() constructor.
  • Series from a dictionary: the keys of the dictionary are used as the index of the Series.
  • Series from a scalar value: an index must be provided. The scalar value is repeated until all the index labels are filled.
  • Series using NumPy functions: functions such as numpy.linspace() and numpy.random.randn() can also be used to create a Series.
  • Series using the range function: pass a Python range to the constructor.

Sample code:

import pandas as pd
import numpy as np

print(pd.Series())  # Empty Series

data = np.array([10, 20, 30, 40, 50])
series = pd.Series(data)  # Series from a NumPy array

list_data = ['s', 'c', 'i', 'e', 'n', 'c', 'e']
list_ser = pd.Series(list_data)  # Series from a list

dict_data = {'First_Box': 50, 'Second_Box': 100, 'Third_Box': 150}
dict_ser = pd.Series(dict_data)  # Series from a dictionary

scl_ser = pd.Series(10, index=[0, 1, 2, 3, 4, 5])  # Series from a scalar value

np_ser1 = pd.Series(np.linspace(3, 33, 3))  # Series using a NumPy function
np_ser2 = pd.Series(np.random.randn(3))     # Series using a NumPy function

rng_series = pd.Series(range(5))  # Series using the range function
What is a DataFrame in Pandas?

A DataFrame in Pandas is a two-dimensional, size-mutable, labeled data structure with columns that can hold different data types. It is essentially a powerful and flexible spreadsheet-like structure within Python, designed for efficient data analysis and manipulation. Some key characteristics of a DataFrame:

  • Rows and columns: data is organized in a tabular format with rows and columns.
  • Heterogeneous data: columns can hold different data types (integers, strings, floats, booleans, etc.).
  • Labeled axes: each row has an index label (often used as the row label) and each column has a name.
  • Relationships between rows and columns: data in different columns can be related and analyzed together.

Example:

import pandas as pd

data = {'column1': [1, 2, 3], 'column2': ['a', 'b', 'c']}
df = pd.DataFrame(data)  # Create a DataFrame from a dictionary

Common operations on DataFrames:

  • Accessing data: using indexing and selection techniques to retrieve specific values or subsets of data.
  • Data manipulation: cleaning, transforming and organizing data using various methods.
  • Mathematical operations: performing calculations on data within or between columns.
  • Aggregation and grouping: summarizing data by groups or applying functions to groups.
  • Merging and joining: combining data from multiple DataFrames based on certain criteria.
What are the different ways to create a DataFrame in Pandas?

Like a Series, a DataFrame can be created in several ways:

  • Empty DataFrame: call the pandas.DataFrame() constructor without any data.
  • From a list or list of lists: pass the list to the DataFrame() constructor. For a list of lists, pass the main list along with the column names.
  • From a dictionary: pass the dictionary to the DataFrame() constructor. The keys become the column names and the values become the data of the columns.
  • From a Pandas Series: a Series can also be passed to the constructor to create a DataFrame.

Example:

lst = ['Alphabet', 'Binary', 'Correlation', 'Database']

df3 = pd.DataFrame(lst1, columns=['Id', 'Data'])  # From a list of lists

data = {'Name': ['Tom', 'nick', 'krish', 'jack'], 'Age': [20, 21, 19, 18]}
df4 = pd.DataFrame(data)  # From a dictionary

lst5 = pd.Series(['Alphabet', 'Binary', 'Correlation', 'Database'])
print(pd.DataFrame(lst5))  # From a Series
How can we create a copy of a Series or DataFrame?

There are two ways to copy a Series or DataFrame: a shallow copy and a deep copy.

Shallow copy: a new object is created, but the indices and the data of the original object are not copied. Only the references to them are copied. In pandas versions before 3.0, this means a change made through one object is reflected in the other. From pandas 3.0, Copy-on-Write is the default, so modifying a shallow copy no longer changes the original.

og_series = pd.Series(range(10))
dummy = og_series.copy(deep=False)  # Shallow copy using the copy() function
dummy2 = og_series                  # Plain assignment: not a copy, both names refer to the same object

Deep copy: a new object with its own indices and data. Changes made to the copy are not reflected in the original Series or DataFrame. This is the default for copy().

og_series = pd.Series(range(10))
dummy = og_series.copy(deep=True)  # Deep copy using the copy() function

How do you access the first and last few rows of a DataFrame?

Pandas has built-in methods for this: head() and tail().

What is reindexing in Pandas?

Reindexing is a technique for changing the row or column labels (index) of a DataFrame or Series. It lets you conform the data to a new set of labels while optionally filling in missing values.

Purpose:

  • Rearrange existing data based on a new set of labels.
  • Insert missing values for labels that are not present in the original data.

Functionality:

  • df.reindex(new_index): reindexes the DataFrame or Series using the provided new_index.
  • Options to handle missing values: fill_value specifies a value to fill missing entries (the default is NaN), and method defines a filling method (e.g. 'ffill' for forward fill, 'bfill' for backward fill).
import pandas as pd

data = {'col1': [1, 2, 3], 'col2': [10, 20, 30]}
df = pd.DataFrame(data, index=['A', 'B', 'C'])

new_index = ['A', 'X', 'B', 'Y', 'C']
reindexed_df = df.reindex(new_index, fill_value=0)  # missing labels are filled with 0
print(reindexed_df)
# Output:
#    col1  col2
# A     1    10
# X     0     0
# B     2    20
# Y     0     0
# C     3    30
How do you select a single column of a DataFrame?

There are two primary ways to select a single column from a DataFrame:

  • Square brackets (bracket notation): the most common and intuitive approach. Write the DataFrame followed by the column name inside square brackets, e.g. df['column_name'].
  • Dot notation (attribute access): less common. It works only if the column name is a valid Python attribute name (no spaces or special characters), e.g. df.column_name.

Which method to use?

Dot notation is generally discouraged because it can conflict with actual DataFrame attributes or methods. Square brackets (df['column_name']) are safer, more explicit and work in every case.

  • Use the rename() function. It can rename a single column or several columns at once.

Direct assignment is less flexible but works for simple renaming of a single column:

df['new_name'] = df['old_name']

Another way is the set_axis() function, which takes the new column names and the axis to replace. It returns a new DataFrame (the inplace argument has been removed):

df = df.set_axis(['COLUMN_1', 'COLUMN_2'], axis=1)

To add a prefix or suffix to all column names, use add_prefix() or add_suffix():

df = df.add_prefix('PREFIX_')
df = df.add_suffix('_suffix')
How do you add an index, row or column to an existing DataFrame?
  • Add a column: assign a list, Series or scalar to a new column name: df['new_col'] = values.
  • Add a row: use df.loc[len(df)] = [...] to place a row at the next position, or combine DataFrames with pd.concat(). The older DataFrame.append() has been removed.
  • Add an index: use df.set_index('col') to turn a column into the index, or assign a list directly with df.index = [...].
import pandas as pd

df = pd.DataFrame({'Name': ['Tom', 'Nick'], 'Age': [20, 21]})

# Add a column
df['City'] = ['Pune', 'Delhi']

# Add a row (using loc with the next index position)
df.loc[len(df)] = ['Krish', 19, 'Mumbai']

# Add a row (using concat)
new_row = pd.DataFrame([{'Name': 'Jack', 'Age': 18, 'City': 'Chennai'}])
df = pd.concat([df, new_row], ignore_index=True)

# Set a column as the index
df = df.set_index('Name')
print(df)
# Output:
#        Age     City
# Name               
# Tom     20     Pune
# Nick    21    Delhi
# Krish   19   Mumbai
# Jack    18  Chennai

What is a Timedelta in Pandas?

A Timedelta is the difference between two dates or times. Similar to the timedelta object in the Python datetime module, a Pandas Timedelta represents a duration or a difference in time. Pandas has a dedicated data type for handling durations or time differences in a DataFrame or Series.

A Timedelta object is created with pd.Timedelta(), providing the number of weeks, days, hours, minutes, seconds, milliseconds, etc. as parameters.

duration = pd.Timedelta(days=7, hours=4, minutes=30, seconds=23)

With the Timedelta data type you can easily perform arithmetic, comparisons and other time-related manipulations. It can express durations in different units such as days, hours, minutes, seconds, milliseconds and microseconds.

duration + pd.Timedelta('2 days 6 hours')  # Timedelta('9 days 10:30:23')

Using pandas.to_datetime() to convert a string to a datetime object:

How do you do feature encoding with Pandas methods?

Pandas has a few built-in methods for feature encoding.

Label encoding:

Label encoding converts categorical data into numerical data so that a machine-learning model can use it. With Pandas, use pandas.Categorical().codes or pandas.factorize() to replace the categorical values with numerical values.

One-hot encoding:

One-hot encoding represents categorical data as numerical values in a machine-learning model. It creates a separate binary variable for each category in the data. The value of the binary variable is 1 if the observation belongs to that category and 0 otherwise. It can improve the performance of the model. To apply one-hot encoding, create dummy columns for the DataFrame using the get_dummies() method.

How do you handle missing data in Pandas?

Handling missing data is a common task in data analysis, and Pandas provides several methods to do it efficiently. Here are the common techniques for detecting, dropping and filling missing data.

Detecting missing data

1. isnull() and notnull()

These methods return a DataFrame of the same shape as the original, where each element is a boolean indicating whether the value is missing (True) or not (False).

df.isnull()
df.notnull()

2. isna() and notna()

These are aliases for isnull() and notnull().

df.isna()
df.notna()

3. sum()

Summing the result of isnull() or isna() gives the count of missing values per column.

df.isnull().sum()

Dropping missing data: dropna()

df_dropped = df.dropna()                    # drop rows with any missing values
df_dropped = df.dropna(subset=['A', 'B'])  # drop rows with missing values in specific columns
df_dropped = df.dropna(axis=1)             # drop columns with any missing values
df_dropped = df.dropna(how='all')          # drop rows where all elements are missing
df_dropped = df.dropna(thresh=3)           # keep only rows with at least 3 non-NA values

Filling missing data

1. fillna()

Fills missing values with a specified value, or from a dictionary. For forward or backward filling, use ffill() and bfill().

df_filled = df.fillna(0)                             # fill with a specific value
df_filled = df.ffill()                               # forward fill
df_filled = df.bfill()                               # backward fill
df_filled = df.fillna({'A': 0, 'B': 1})              # fill different columns with different values
df_filled = df.fillna(df.mean(numeric_only=True))    # fill with the mean of each numeric column

2. interpolate()

Estimates (interpolates) missing values in a Series or DataFrame.

df_interpolated = df.interpolate()

3. replace()

Replaces missing values with another value.

import numpy as np

df_replaced = df.replace(np.nan, 0)
Why doesn’t DataFrame.shape have parentheses?

In Pandas, DataFrame.shape does not have parentheses because it is an attribute of the DataFrame, not a method. Here is the difference between attributes and methods, and why shape is an attribute:

  • Attributes: variables associated with a DataFrame object. They store information about the DataFrame and do not require parentheses when accessed.
  • Methods: functions associated with a DataFrame object. They perform operations on the DataFrame and often take additional arguments. Methods require parentheses to be called, even if they take no arguments.
df.shape    # attribute: no parentheses, e.g. (3, 2)
df.head()   # method: parentheses required
What is a rolling mean and how do you calculate it in Pandas?

A rolling mean, also known as a moving average, is a statistical method used to analyze time series data by calculating the average of different subsets of the full dataset. In Pandas, the rolling() function creates a rolling window that can be followed by an aggregation function such as mean(), sum() or max() to compute rolling statistics.

Calculating a rolling mean in Pandas:

DataFrame.rolling(window, min_periods=None, center=False, win_type=None, on=None).mean()

Parameters

  • window: size of the moving window, i.e. the number of observations used to calculate the statistic.
  • min_periods: minimum number of observations in the window required to have a value (the default is the size of the window).
  • center: set the labels at the center of the window (default is False).
  • win_type: a window type (e.g. 'boxcar', 'triang', 'blackman') if using weighted windows.
  • on: for a DataFrame, the column to use for the rolling calculation.

Example:

s = pd.Series([1, 2, 3, 4, 5, 6])
print(s.rolling(window=3).mean())
# Output:
# 0    NaN
# 1    NaN
# 2    2.0
# 3    3.0
# 4    4.0
# 5    5.0
# dtype: float64
How do you use the pd.cut() and pd.qcut() functions in Pandas?

The pd.cut() and pd.qcut() functions are used for binning or discretizing continuous data into discrete intervals or bins. They help categorize numerical data, making it easier to analyze distributions and patterns.

pd.cut()

The pd.cut() function segments and sorts data values into bins or intervals. You can specify the exact bin edges or the number of equal-width bins.

pd.cut(x, bins, right=True, labels=None, retbins=False, precision=3, include_lowest=False, duplicates='raise')

Parameters

  • x: the data to be binned (array-like).
  • bins: the criteria to bin by. Can be an integer for the number of equal-width bins, or a sequence of bin edges.
  • right: whether the intervals are closed on the right (default is True).
  • labels: labels for the resulting bins. If False, returns only integer indicators.
  • retbins: whether to return the bins or not (default is False).
  • precision: precision at which to store and display the bin labels.
  • include_lowest: whether the first interval should be left-inclusive or not.
  • duplicates: whether to allow bin edges of the same value or not.
ages = pd.Series([5, 17, 25, 40, 62, 80])
print(pd.cut(ages, bins=[0, 18, 60, 100], labels=['child', 'adult', 'senior']))
# Output:
# 0     child
# 1     child
# 2     adult
# 3     adult
# 4    senior
# 5    senior
# dtype: category

pd.qcut()

The pd.qcut() function segments and sorts data values into bins based on quantiles, so each bin has (approximately) the same number of data points.

pd.qcut(x, q, labels=None, retbins=False, precision=3, duplicates='raise')

Parameters

  • x: the data to be binned (array-like).
  • q: the number of quantiles (e.g. 4 for quartiles, 10 for deciles) or a list of quantiles.
  • labels: labels for the resulting bins. If False, returns only integer indicators.
  • retbins: whether to return the bins or not (default is False).
  • precision: precision at which to store and display the bin labels.
  • duplicates: whether to allow bin edges of the same value or not.
scores = pd.Series([1, 2, 3, 4, 5, 6, 7, 8])
print(pd.qcut(scores, q=4, labels=['Q1', 'Q2', 'Q3', 'Q4']))
# Output:
# 0    Q1
# 1    Q1
# 2    Q2
# 3    Q2
# 4    Q3
# 5    Q3
# 6    Q4

How do you use the query() function in Pandas?

The query() function provides a convenient way to filter DataFrame rows using a query string. It allows a more readable, SQL-like syntax for row selection.

DataFrame.query(expr, inplace=False, **kwargs)

Basic:

result = df.query('age > 25')

Multiple conditions:

result = df.query('age > 25 and score > 80')

String operations:

result = df.query('name.str.startswith("A") or name.str.startswith("D")')
