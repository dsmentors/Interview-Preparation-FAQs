What are Measures and Dimensions?
  • Measures: quantitative data, typically numerical, that can be aggregated. They are used for calculations such as sums and averages. Examples: sales revenue, profit and quantity sold.
  • Dimensions: qualitative data, typically categorical, used to slice and dice the measures. They give the data context. Examples: product names, regions and dates.

How many maximum tables can you join in Tableau?

In Tableau, you can join up to 32 tables in a single data source.

What is Data Blending?

Data blending is a technique used to combine data from multiple data sources. Unlike joins, which combine tables from a single data source, blending lets you work with data from different sources as if they were from the same source.

The primary data source drives the visualization, and the secondary data source supplements it with related data.

What is the default Data Blending Join?

The default data blending join in Tableau is a left join. The primary data source is the left table and the secondary data source is the right table. The blend includes all rows from the primary source and only the matching rows from the secondary source.

Will making changes in the Story reflect in the Worksheet and Dashboard?

No. Changes made in the Story will not reflect in the worksheets or dashboards. A Story is a sequence of sheets that tells a narrative, and it does not affect the underlying worksheets or dashboards.

However, changes in worksheets and dashboards will reflect in the Story if those elements are part of the Story.

How do you parameterize components in your reports?

Parameters let you dynamically change values in calculations, filters or reference lines. You can create a parameter to let users interactively control a value, such as selecting a date range, adjusting a threshold, or switching between different measures.

Example: create a parameter that lets users select a region, which then filters the data to show results only for that region.

Explain different types of JOINS supported by Tableau.

Tableau supports the following types of joins:

  • Inner join: returns only the rows with matching keys in both tables.
  • Left join: returns all rows from the left table and the matching rows from the right table. Non-matching rows from the right table are filled with nulls.
  • Right join: returns all rows from the right table and the matching rows from the left table. Non-matching rows from the left table are filled with nulls.
  • Full outer join: returns all rows when there is a match in either table. Non-matching rows are filled with nulls.

What is a Calculation Field?

A calculated field is a new field created by the user to calculate data dynamically. It lets you create new data from existing data in your dataset by applying formulas or calculations.

For example, a calculated field for profit, subtracting the cost from the revenue:

Profit = [Revenue] - [Cost]
What’s a Heat Map?

A heat map is a visualization that displays data in a matrix format, where individual values are represented by different colors. It shows the magnitude of a phenomenon as color in two dimensions, with the colors determined by the values of the data points. Heat maps are particularly useful for spotting patterns, trends and correlations in data.

What’s a Tree Map?

A tree map displays hierarchical data using nested rectangles. Each branch of the hierarchy gets a rectangle, which is then tiled with smaller rectangles representing its sub-branches. The area of each rectangle is proportional to the data value it represents. Tree maps are useful for displaying large amounts of hierarchical data in a compact space.

What’s a Bullet Graph?

A bullet graph is a variation of a bar chart, developed by Stephen Few, used to display a single measure against a target or to compare performance against a benchmark. It includes:

  • a main bar that shows the primary measure,
  • a vertical line that marks the target, and
  • background bars for qualitative ranges (for example poor, average, good).
What’s a Gantt Chart?

A Gantt chart is a type of bar chart that represents a project schedule. It shows the start and finish dates of the elements of a project. In Tableau, Gantt charts give a visual representation of tasks or activities over time, where the length of each bar represents the duration of the task.

What’s a Dual Axis?

A dual axis chart plots two measures on the same chart with two different axes (left and right). It is particularly useful when you want to compare two related metrics that have different scales, such as sales revenue and profit margin.

Name All Types of Filters Available in Tableau

Tableau offers several types of filters:

  • Extract filters: applied when you extract data from a data source.
  • Data source filters: applied at the data source level, filtering data across all worksheets that use that data source.
  • Context filters: an independent filter that creates a context for all other filters.
  • Dimension filters: applied to categorical data.
  • Measure filters: applied to quantitative data.
  • Table calculation filters: applied to the results of table calculations.
  • Relative date filters: filter data based on date ranges relative to the current date.
  • Top N filters: show only the top N values.
What Are the Components of a Dashboard in Tableau?

A Tableau dashboard consists of the following components:

  • Views: the visualizations themselves.
  • Legends: explain the meaning of the colors, sizes and shapes used.
  • Filters: let users interact with the dashboard and change the views based on certain criteria.
  • Parameters: user-defined variables that can drive interactive elements in the dashboard.
  • Text, images and web content: static elements that add context or branding.
  • Actions: define interactivity between the sheets within the dashboard.
What’s a Blended Axis?

A blended axis is used when you want to blend two measures into a single axis in the same chart. The measures share the same axis and are plotted as overlapping or side-by-side bars.

Do We Have Any Way to Handle Null Values in Tableau?

Yes, Tableau provides several ways to handle null values:

  • Filter out null values using the Filters shelf.
  • Replace null values with a specific value, using the ZN function for measures or the IFNULL function for dimensions.
  • Show null values as a specific label or color in your visualization.
What is a Pareto Chart?

A Pareto chart contains both bars and a line graph. The bars show individual values in descending order, and the line shows the cumulative total. It is based on the Pareto principle, which states that 80% of effects come from 20% of the causes. Pareto charts help identify the most significant factors in a dataset.

What is Disaggregation and Aggregation of Data?
  • Aggregation: combining multiple values into a single value, such as a sum, average or count.
  • Disaggregation: displaying all data points individually without aggregating them. This is useful when you want to see the raw data points rather than a summarized view.

How Do You Create Cascading Filters Without Using a Context Filter?

Cascading filters (also called dependent filters) are filters where the choices in one filter depend on what is selected in another.

The simplest way without a context filter is the Only Relevant Values option:

  1. Show the filters as quick filters (right-click the filter and choose Show Filter).
  2. Open the dropdown of the dependent filter and choose Only Relevant Values.
  3. Now its list only contains the values that remain after the other filters are applied. For example, after picking a Region, the State filter lists only the states of that region.

Other ways to get the same result:

  • Filter actions on a dashboard, where selecting a mark in one sheet filters the others.
  • Calculated fields or sets that depend on the selections of other filters or parameters.
